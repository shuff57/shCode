## Overview

Ten buggy variable declarations are waiting for you. Your job: find every bug, fix it so the program runs cleanly, and leave a `//` comment on each fixed line explaining exactly what was wrong.

This is your first debugging lab. Good debuggers don't just "make it work" — they explain *why* it was broken.

---

## Task

Open the starter file below in DevTools (Console tab) or the in-app editor. The file has **10 bugs** spread across wrong syntax, reserved words, naming violations, type errors, and misuse of `const`. Fix all 10 and add an inline comment after each fix.

### Starter file

```js
// A2.1 — Variable Bug Hunt
// Fix all 10 bugs. After each fix, add a // comment explaining what was wrong.

1age = 17;                      // bug 1
const let name = "Jordan";      // bug 2
let  hobby = running;           // bug 3
CONST zip = 95928;              // bug 4
let userName = "Alex"           // bug 5
let class = "CSCI 4";           // bug 6
const temperature = 72;
temperature = 80;               // bug 7
let 'phone' = "555-0123";       // bug 8
let is-waterproof = true;       // bug 9
console.log(fav_color);         // bug 10
```

### What to look for

Each bug belongs to one of these categories — there is at least one of each:

- Invalid variable name (starts with a digit, contains a hyphen, wrapped in quotes)
- Reserved word used as a variable name
- Undeclared keyword or misused keyword (`CONST`, `const let`)
- Missing declaration keyword (undeclared variable)
- Missing quotes around a string value
- Missing semicolon at end of statement
- Reassignment of a `const` variable
- Reference to a variable that was never declared

## How to submit

1. Run your fixed file; confirm no errors appear in the console.
2. Copy the final code (fixes + comments) into the assignment submission box.

---

## Tips

- Run the broken starter line-by-line in DevTools first. The error message usually names the exact line.
- A bug can be on a **different line** than the one marked — read the line above and below the marker too.
- Bug 10 requires you to add something, not just change syntax.
