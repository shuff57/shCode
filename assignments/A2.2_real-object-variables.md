## Overview

Pick a real physical object — something in your classroom, bedroom, or kitchen. Write a JavaScript program that describes it using properly typed variables, template literals, and string methods.

The goal is to practice *choosing the right data type for the right job*, not just making the computer print something. A variable called `width` should hold a number. A variable called `material` should hold a string. A variable called `isWaterproof` should hold a boolean. Each variable should earn its place.

---

## Task

Write a program in the in-app editor (or DevTools) that:

1. Declares **at least 6 variables** describing a single real physical object.
2. Prints a **multi-line description** of that object using `console.log`.

### Requirements

| # | Requirement |
|---|-------------|
| 1 | At least **2 number variables** (dimensions, weight, count, price, etc.) |
| 2 | At least **2 string variables** (name, material, color, brand, etc.) |
| 3 | At least **1 boolean variable** (is it waterproof? rechargeable? in use?) |
| 4 | Uses **template literals** (backtick strings + `${...}`) — do not use `+` concatenation to build output lines |
| 5 | Uses at least **2 string methods** from: `.length`, `.toUpperCase()`, `.toLowerCase()`, `.includes()` |
| 6 | All variable names follow **camelCase** and are **descriptive** |
| 7 | Every variable declaration has a `//` comment (one line) explaining what it represents |
| 8 | Prints at least **3 lines** of meaningful description via `console.log` |

---

## Example

Here is what a complete submission might look like for a coffee mug. Your object should be different.

```js
// A2.2 — Real Object Variable Program
// Object: coffee mug

const itemName = "Morning Mug";       // what the mug is called
const material = "ceramic";           // what it's made of
const volumeOz = 12;                  // liquid capacity in fluid ounces
const volumeMl = 355;                 // same capacity in milliliters
const isDishwasherSafe = true;        // whether it can go in the dishwasher
const color = "white";                // exterior color

console.log(`This ${itemName.toUpperCase()} holds ${volumeOz} oz of liquid (volume: ${volumeMl} mL).`);
console.log(`Material: ${material} (dishwasher-safe: ${isDishwasherSafe}).`);
console.log(`Its name "${itemName.toUpperCase()}" is ${itemName.length} characters long.`);
```

**Expected output:**

```
This MORNING MUG holds 12 oz of liquid (volume: 355 mL).
Material: ceramic (dishwasher-safe: true).
Its name "MORNING MUG" is 10 characters long.
```

## Tips

- Good object choices: a water bottle, a book, a shoe, a phone, a desk lamp, a backpack.
- Not sure which variables to declare? List 8–10 facts about your object first (in plain English), then figure out the data type for each fact.
- The `.length` property works on any string: `"hello".length` is `5`. Use it to add an interesting fact about your object's name.
- Template literals use backticks (`` ` ``), not single or double quotes. They let you write `${variableName}` directly inside the string.
