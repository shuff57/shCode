## Overview

You will receive a short program that works but is poorly written — bad variable names, missing spaces, no comments, no structure. Your job is to fix it so that a stranger (or future-you) can understand it at a glance.

This is the first assignment graded against the **Class Coding Style Guide** you received this week. Keep it handy.

---

## Starter File

Your teacher will distribute `A3.1_messy-program-starter.js`. It contains the following code:

```js
let p=29.99
let t=0.0725
let n="USB Cable"
let q=3
let s=p*q
let tax=s*t
let total=s+tax
console.log(n+" qty "+q+" subtotal $"+s.toFixed(2))
console.log("tax $"+tax.toFixed(2)+" total $"+total.toFixed(2))
let onSale=true
if(onSale){console.log("ON SALE!")}
```

Do not change what the program **does** — only change how it is written. The output must remain identical.

---

## Deliverables

Submit two files:

### 1. Rewritten `.js` file

Your cleaned-up version must have ALL of the following:

- **Descriptive camelCase names** — rename every single-letter variable to something meaningful (`p` → `unitPrice`, `t` → `taxRate`, `n` → `productName`, `q` → `quantity`, `s` → `subtotal`, etc.)
- **2-space indentation** — every line inside a block (`if`, `else`) must be indented exactly 2 spaces
- **Semicolons on every statement** — no exceptions
- **An inline `//` comment on every line** — explain what the line does in plain English
- **Spaces around operators and after commas** — `p * q`, not `p*q`; `func(a, b)`, not `func(a,b)`
- **Template literals instead of `+` concatenation** — replace every `" " + variable + " "` pattern with a template literal (backtick string with `${}`)

### 2. A `README.md` file

A short README with exactly these three sections:

```md
## What it does
<1–2 sentences describing what the program calculates and prints>

## How to run it
<1 sentence — e.g., "Paste into the DevTools console and press Enter.">

## Example output
<Copy and paste the 3 lines your program actually prints>
```

Fill in the angle-bracket placeholders with real content. Do not submit angle brackets.

## Tips

- Run your finished program in DevTools before submitting. If the output changes, you introduced a bug — compare with the starter output.
- The `if` block has one line inside it. That line still needs a comment AND correct indentation.
- Template literals use backticks (\`\`), not quotes. Example: `` `${productName} qty ${quantity}` ``
- If you are unsure what a variable does, trace the math: `p * q` is price × quantity = subtotal.
