## Teacher recording notes

If you record V1 and V2 yourself, aim for:

- **V1 (5 min):** Open the in-app editor on-camera, paste nothing — type every character. Show Run button, show Output, point at what each line does. Save this as the canonical "first sketch" video for the year.
- **V2 (3 min):** Whiteboard + hand-drawn timeline. Show the single `setup()` call on the left, then ~60 `draw()` calls per second stretched across the rest of the board. Emphasize: if you put `new Sprite()` in `draw()` you make 60 sprites per second — a classic beginner bug.
