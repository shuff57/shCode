# Module 2.1.1 — Hello Sprite and Movement

**Week 10 · Q2 moSHion Foundations · 3.5 contact hours**
Welcome to Quarter 2. This week your code becomes visual.

---

## What you'll learn

By the end of this module you will be able to:

1. Create a canvas and place sprites on it.
2. Structure a moSHion sketch with `setup()` and `draw()`.
3. Drive a sprite with the keyboard using `kb.pressing()` and `vel.x / vel.y`.
4. Explain the frame loop: `draw()` runs ~60 times per second.
5. Avoid two classic bugs: the drifting sprite (forgot else-to-zero) and the 60-sprites-per-second bug (new Sprite in draw).

## Key vocabulary you'll need

| Term | What it means |
|------|--------------|
| **Canvas** | The drawing area you create with `new Canvas(w, h)` |
| **Sprite** | A visual, physics-aware object |
| **Frame** | One pass through `draw()` — happens ~60 times/second |
| **`vel`** | Velocity — pixels moved per frame |
| **`kb.pressing(key)`** | Returns `true` *while* a key is held |

## Still stuck?

- Sprite drifting forever? You forgot the `else` branch that resets velocity to 0.
- Canvas looks like it's painting trails? You forgot `background(...)` at the start of `draw()`.
- Sprite shoots off-screen? Your velocity is too high. Try 2–6.
- Sprite keeps making copies? You put `new Sprite(...)` inside `draw()` instead of `setup()`.

Ask in class or drop a question in the platform discussion.
