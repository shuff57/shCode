## Overview

In this lab you will run five JavaScript statements and take a screenshot of your results. You have two paths — choose whichever works best for you. Both paths count equally.

---

## Path A — Browser DevTools (authentic)

### Step 1: Open Your Browser

Use **Google Chrome** (recommended) or **Microsoft Edge**. These instructions are for Chrome, but Edge works the same way.

### Step 2: Open the Developer Console

Choose one method:

| Method | How |
|--------|-----|
| **Keyboard (Chromebook)** | Press `Ctrl + Shift + J` |
| **Keyboard (Windows)** | Press `Ctrl + Shift + J` or `F12`, then click the "Console" tab |
| **Keyboard (Mac)** | Press `Cmd + Option + J` |
| **Menu** | Click the three-dot menu (top right) > More Tools > Developer Tools > Console tab |

You should see a panel open at the bottom or side of your browser with a blinking cursor next to a `>` symbol. This is the **console** — where you will type code.

### Step 3: Test It

Type the following and press Enter:

```
2 + 2
```

If you see `4` appear below your input, the console is working.

### Step 4: Run the 5 Statements

Type each statement into the console **one at a time**. Press Enter after each one.

---

#### Statement 1: Your First Output

```js
console.log("Hello, world!");
```

**What you should see:** `Hello, world!` printed in the console.

**What's happening:** `console.log()` prints whatever is inside the parentheses. The text inside the quotes is called a **string**.

---

#### Statement 2: Math

```js
console.log(2 + 2);
```

**What you should see:** The number `4` printed in the console.

**What's happening:** No quotes means it's a number. JavaScript calculates the answer and prints the result.

---

#### Statement 3: Combining Text

```js
console.log("My name is " + "a programmer!");
```

**What you should see:** `My name is a programmer!`

**What's happening:** The `+` operator joins two strings together. This is called **concatenation**.

---

#### Statement 4: True or False

```js
console.log(100 > 50);
```

**What you should see:** `true`

**What's happening:** `100 > 50` asks "is 100 greater than 50?" The answer is `true` — a **boolean** value.

---

#### Statement 5: Your Own Message

```js
console.log("I just ran my first JavaScript code!");
```

**What you should see:** `I just ran my first JavaScript code!`

---

### Step 5: Screenshot

After running all 5 statements, your console should show all outputs together. Take a screenshot:

| Platform | Shortcut |
|----------|----------|
| **Chromebook** | `Ctrl + Shift + Show Windows` (rectangle key), then drag to select |
| **Windows** | `Win + Shift + S`, then drag to select |
| **Mac** | `Cmd + Shift + 4`, then drag to select |

## Troubleshooting

| Problem | Solution |
|---------|----------|
| I don't see a `>` cursor | Make sure you clicked the **Console** tab, not Elements or Network |
| It says "undefined" after my `console.log` | That's normal — `console.log()` prints your message AND returns `undefined`. The printed message is what counts |
| Red error message | Check your typing: quotes must match (`"..."`), parentheses must close, and `console.log` must be spelled exactly right |
| Nothing happens when I press Enter | Make sure you're clicking inside the console input area (next to the `>`) before typing |
| Smart quotes / curly quotes (`""`) | The console needs straight quotes. If autocorrect is changing them, try typing the quote differently |
