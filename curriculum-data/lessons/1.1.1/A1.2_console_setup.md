## Overview

In this lab you will open the browser developer console, run five JavaScript statements, and take a screenshot of your results. This is your first time writing real code — by the end, you'll have proof that you can make a computer do what you tell it.

---

## Setup Instructions

### Step 1: Open Your Browser

Use **Google Chrome** (recommended) or **Microsoft Edge**. These instructions are for Chrome, but Edge works the same way.

### Step 2: Open the Developer Console

Choose one method:

| Method | How |
|--------|-----|
| **Keyboard (Chromebook)** | Press `Ctrl + Shift + J` |
| **Keyboard (Windows)** | Press `Ctrl + Shift + J` or `F12` then click the "Console" tab |
| **Keyboard (Mac)** | Press `Cmd + Option + J` |
| **Menu** | Click the three-dot menu (top right) > More Tools > Developer Tools > Console tab |

You should see a panel open at the bottom or side of your browser with a blinking cursor next to a `>` symbol. This is the **console** — where you will type code.

### Step 3: Test It

Type the following and press Enter:
```
2 + 2
```

If you see `4` appear below your input, the console is working. You're ready to go.

## The 5 Statements

Type each statement into the console **one at a time**. Press Enter after each one. Watch what appears in the console output.

### Statement 1: Your First Output
```js
console.log("Hello, world!");
```
**What you should see:** The text `Hello, world!` printed in the console.

**What's happening:** `console.log()` is a JavaScript command that prints whatever is inside the parentheses. The text inside the quotes is called a **string**.

---

### Statement 2: Math
```js
console.log(2 + 2);
```
**What you should see:** The number `4` printed in the console.

**What's happening:** JavaScript can do math. Notice there are no quotes around `2 + 2` — that's because numbers are not strings. JavaScript calculates the answer and prints the result.

---

### Statement 3: Combining Text
```js
console.log("My name is " + "a programmer!");
```
**What you should see:** The text `My name is a programmer!` printed in the console.

**What's happening:** The `+` operator joins two strings together. This is called **concatenation**. Notice the space after "is " — without it, the words would smash together.

---

### Statement 4: True or False
```js
console.log(100 > 50);
```
**What you should see:** The word `true` printed in the console.

**What's happening:** JavaScript can compare values. `100 > 50` asks "is 100 greater than 50?" The answer is `true`. This is called a **boolean** — a value that is either `true` or `false`.

---

### Statement 5: Your Own Message
```js
console.log("I just ran my first JavaScript code!");
```
**What you should see:** The text `I just ran my first JavaScript code!` printed in the console.

**What's happening:** Same as Statement 1 — you're printing a string. But this time, the message is yours. You just wrote and ran real JavaScript.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| I don't see a `>` cursor | Make sure you clicked the **Console** tab, not Elements or Network |
| It says "undefined" after my console.log | That's normal! `console.log()` prints your message AND returns `undefined`. The printed message is what matters |
| Red error message | Check your typing. Make sure quotes match (`"..."` not `"..."`), parentheses are closed, and you spelled `console.log` exactly right |
| Nothing happens when I press Enter | Make sure you're clicking inside the console input area (next to the `>`) before typing |
| My smart quotes look curly (`""`) | The console needs straight quotes (`""`). If your keyboard is autocorrecting, try typing the quote while holding Shift |
