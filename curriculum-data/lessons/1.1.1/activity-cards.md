## Activity 6: Introduction to JavaScript

| | |
|---|---|
| **Source** | freeCodeCamp JavaScript v9 |
| **Type** | Theory |
| **Time** | ~20 minutes |
| **Link** | [freeCodeCamp > Learn JavaScript](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures-v8/) |

### Objective
Learn what JavaScript is and see your first JavaScript statements.

### What To Do
1. Go to the freeCodeCamp link above and begin the "Introduction to JavaScript" section
2. Read through the lesson content carefully — do not rush
3. Key concepts to focus on:
   - JavaScript is the programming language of the web
   - A **statement** is a single instruction the computer follows
   - `console.log()` is how you print output in JavaScript
4. Try typing this in the lesson environment:
   ```js
   console.log("Hello!");
   ```
5. Notice what appears in the output area

### Expected Outcome
You understand that JavaScript is a programming language used on the web, and you have successfully run at least one `console.log()` statement.

## Activity 9: Your First Karel Program

| | |
|---|---|
| **Source** | CodeHS AP CSP, Section 1.2.4 |
| **Type** | Exercise |
| **Time** | ~15 minutes |
| **Link** | [CodeHS Course 266371 > Section 1.2.4](https://codehs.com/course/266371/) |

### Objective
Write your first program! Guide Karel to complete a task using the commands you learned.

### What To Do
1. Open the "Your First Karel Program" exercise on CodeHS
2. Read the goal: where does Karel need to go, and what does Karel need to do?
3. Write your program using Karel's commands:
   - `move();` — move forward one space
   - `turnLeft();` — turn 90 degrees to the left
   - `putBall();` — place a ball at the current position
   - `takeBall();` — pick up a ball at the current position
4. Run your program to test it
5. If Karel doesn't end up in the right place, check your command order and try again

### Tips
- Plan your solution on paper first — trace Karel's path with your finger
- Each command goes on its own line
- Don't forget the parentheses `()` and semicolon `;` after each command
- It's okay to make mistakes — debugging is part of programming!

### Expected Outcome
You have written a working Karel program that completes the given task. You wrote it yourself (not copied).

## Activity 11: Hello World (Example)

| | |
|---|---|
| **Source** | CodeHS AP CSP, Section 3.3.3 |
| **Type** | Example |
| **Time** | ~10 minutes |
| **Link** | [CodeHS Course 266371 > Section 3.3.3](https://codehs.com/course/266371/) |

### Objective
See `console.log()` in action and understand how it works.

### What To Do
1. Open the "Hello World" example on CodeHS
2. Read the code before running it:
   ```js
   console.log("Hello, World!");
   ```
3. Run the program — see the output appear in the console
4. Now try modifying the code:
   - Change the text inside the quotes to say something different
   - Add a second `console.log()` on the next line
   - Run it again — both lines should print, in order

### Starter Code (provided in CodeHS)
```js
console.log("Hello, World!");
```

### Try These Modifications
```js
// Change the message
console.log("Hello from JavaScript!");

// Add a second line
console.log("Hello, World!");
console.log("This is my second line of code!");
```

### Expected Outcome
You have run a `console.log()` statement and modified it to print your own message. You see that multiple `console.log()` statements print in order, one per line.

## Activity 12: Your Name and Hobby

| | |
|---|---|
| **Source** | CodeHS AP CSP, Section 3.3.4 |
| **Type** | Exercise |
| **Time** | ~15 minutes |
| **Link** | [CodeHS Course 266371 > Section 3.3.4](https://codehs.com/course/266371/) |

### Objective
Write your first real JavaScript program: print your name and hobby to the console.

### What To Do
1. Open the "Your Name and Hobby" exercise on CodeHS
2. Write a program that:
   - Prints your name on the first line
   - Prints your favorite hobby on the second line
3. Use `console.log()` for each line of output
4. Run your program and verify both lines appear

### Starter Code
```js
// Your Name and Hobby
// Write two console.log statements below:
// 1. Print your name
// 2. Print your favorite hobby

```

### Example Solution (yours will be different!)
```js
// Your Name and Hobby
console.log("Maria Garcia");
console.log("I love playing soccer and building things.");
```

### Bonus Challenge
Add a third `console.log()` that prints why you chose that hobby. For example:
```js
console.log("I started playing soccer when I was 6 and my team won the city tournament last year.");
```

### Expected Outcome
Your program prints at least two lines to the console: your name and your hobby. Each line uses its own `console.log()` statement.
