## Learning Objectives

By the end of this lesson, students will be able to:

1. Define what a program is and what programming languages are
2. Describe the software development life-cycle (design, development, testing, deployment, maintenance)
3. Set up and use the browser DevTools console
4. Write and run a first JavaScript statement using `console.log()`

## Session Plan

### Session 1 (~105 min)

**Opening (10 min):**
- Ask students: "Name three apps you used today. What do they have in common?"
- Brief intro: everything they named was built by programmers writing code

**Activities 1-6 (~70 min):**
- Work through the conceptual videos and connections
- After Activity 3, pause for class discussion: "What's the difference between software and hardware? Give an example of each."
- After Activity 5, ask: "What job do you want? How might programming help?"
- Activity 6 transitions into hands-on: students follow the FCC lesson on what JavaScript is

**SDLC Discussion (15 min):**
- Teacher presents the five phases: Design, Development, Testing, Deployment, Maintenance
- Walk through a familiar app (e.g., Instagram) through each phase
- Students take notes for A1.1

**Assign A1.1 (10 min):**
- Distribute assignment, review rubric
- Due next session

### Session 2 (~105 min)

**Activities 7-9: Karel (~35 min):**
- Watch Karel video, then see the example program
- Students write their first Karel program (Activity 9)
- Debrief: "You just wrote a program. A program is a set of instructions the computer follows in order."

**Activities 10-12: Hello World in JS (~35 min):**
- Watch Hello World video, then see the console.log example
- Students complete Activity 12: write their own console.log statements

**Lab A1.2 (20 min):**
- Students open DevTools, run the 5 provided statements, screenshot results

**Wrap-up (15 min):**
- Quick vocabulary review: program, programming language, software, hardware, SDLC, console
- Collect A1.1 if not already submitted
- Preview next week: "Now that you can talk to the computer, we'll learn how it remembers things — variables."

---

## Teacher Notes

- **Keep it conceptual.** Resist going deep on syntax. The goal is comfort with the idea of programming, not mastery of JavaScript.
- **Use familiar examples.** Apps students actually use (Instagram, Spotify, Google Maps, Roblox) make the SDLC and "what is a program" discussions feel relevant.
- **Do NOT mention JSCAD yet.** Students will encounter it in Q2. This week is strictly browser console.
- **The lifecycle discussion is critical for SLO 1.** Students must be able to name all five phases. Reinforce this during A1.1 feedback.
- **Karel is a bridge.** Students who struggle with text-based programming can build confidence in the visual Karel environment first. Don't skip it.
- **DevTools may intimidate.** Walk through opening it step-by-step. On Chromebooks: Ctrl+Shift+J. On Mac: Cmd+Option+J.

## Vocabulary

| Term | Definition |
|------|-----------|
| **Program** | A set of instructions that tells a computer what to do |
| **Programming language** | A formal language used to write programs (e.g., JavaScript, Python) |
| **Software** | Programs and data that run on a computer |
| **Hardware** | The physical parts of a computer (screen, keyboard, processor) |
| **SDLC** | Software Development Life-Cycle: the process of planning, creating, testing, and maintaining software |
| **Console** | A text-based tool where you can type and run code, and see output |
| **`console.log()`** | A JavaScript command that prints a value to the console |
| **Algorithm** | A step-by-step set of instructions to solve a problem |
| **Sequential execution** | Code runs one line at a time, from top to bottom |
