Build the complete lesson materials for **Unit 1, Section 1, Activity 1 (1.1.1): What Is Programming / Software Lifecycle**.

**Time:** ~3.5 hours (1 week, two class sessions)

**SLOs covered:** SLO 1 (Describe the software development life-cycle), SLO 4 intro (what an algorithm is)

**Learning Objectives:**
- Define what a program is and what programming languages are
- Describe the software development life-cycle (design → code → test → maintain)
- Set up and use browser DevTools console
- Write and run a first JS statement

**Activity sequence (12 activities, in teaching order):**
1. Welcome to AP CSP [Video] — motivational framing
2. What is Code? [Video] — conceptual intro
3. What is Software [Connection] — software vs hardware
4. Uses of Programs [Video] — programs in daily life
5. Why Should You Learn to Program? [Connection] — career relevance
6. [FCC] Introduction to JavaScript [Theory] — what JS is, first statements, console output
7. Introduction to Programming With Karel [Video] — first program concepts
8. Our First Karel Program [Example] — see a working program
9. Your First Karel Program [Exercise] — write first program
10. Hello World [Video] — transition from Karel to JS
11. Hello World [Example] — console.log in action
12. Your Name and Hobby [Exercise] — first JS exercise

**Assignments to produce:**
- **A1.1 (Written, graded):** 1-page description of the software development life-cycle with a real-world example walking through each phase. (SLO 1 primary coverage)
- **A1.2 (Lab):** Setup checklist — open browser console, run 5 provided `console.log` statements, screenshot results, submit.

**What to generate:**
For each of the 12 activities, produce:
- A student-facing instruction card (title, objective, what to do, expected outcome)
- Any starter code or provided code snippets (for Examples and Exercises)
- Link to the freeCodeCamp resource where applicable (freeCodeCamp JavaScript v9)

For each assignment (A1.1 and A1.2), produce:
- Full student-facing assignment sheet with instructions, rubric, and estimated time
- For A1.2, include the 5 `console.log` statements to run

**Teacher Notes:**
- Keep it conceptual. Resist going deep on syntax.
- Use examples like apps students use daily (Instagram, Spotify, Google Maps).
- Do not mention JSCAD yet.
- The lifecycle discussion should connect to SLO 1 — students must be able to name all phases.

**File naming convention:** `A[original_week].[number]_[short_title].md` (e.g., `A1.1_software_lifecycle.md`, `A1.2_console_setup.md`)

**Style:** Follow the class coding style guide (Appendix A of curriculum-plan.md). All rubrics should reference it. Written assignments include a prompt, length guidance, and a simple rubric. Lab assignments include setup instructions, step-by-step task list, expected output description, and rubric.
