# Module 7.16: Quest: plan and the fighters

**One day.** Part of the Quest chain: one element, ends with something that runs, and the next
module starts from this one's finished game (`CARRY-FORWARD-SPEC.md`).

## The one idea

One class makes every fighter: a constructor stores its name, hp and power, isAlive() answers a question, and a draw(x, y) method draws the fighter and an hp bar scaled by hp / maxHp.

## A finished game up front

Added 2026-11-07 as `7.16.0`, so no existing number moved: a play-only reading of the whole Quest game (`7-16-quest-0-reading-play-the-finished-game`) in the `demo` live-block mode, which hides the code. It is the chain's own game (the Fighter class (7.16), attacks (7.17), the three actions (7.18), the run of enemies (7.19) and the online duel (7.20)) plus a title screen, a winner panel, textures, sound and a rematch key. Online goes through `multiplayer('versus', 2)` and the lobby bar, not the chain's H key and room code; L plays both sides on one computer. Every move is checked in `onMove` on both computers, as in the labs. The reading's table says where each part is built.
