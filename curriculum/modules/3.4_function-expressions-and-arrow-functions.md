# Module 3.4: Function Expressions and Arrow Functions

## Module Goal
Students write the same function three ways (declaration, expression, arrow), know when the shorthand rules apply, and pass a function as an argument to another function.

## Pre-requisite snapshot
Module 3.3 (Arrays) complete.

## Post-requisite snapshot
Students can write and pass a short callback-shaped function — the form Module 3.7 (Array Methods), Module 8.5 (JSCAD array loops), and every later moSHion callback depend on.
