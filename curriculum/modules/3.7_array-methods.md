# Module 3.7: Array Methods

## Module Goal
Students transform, slice, and join arrays without mutating the original, and use spread to build new arrays and objects.

## Pre-requisite snapshot
Module 3.6 (Pass by Value/Reference) complete.

## Post-requisite snapshot
Students can transform a list into a new list without touching the original — the pattern Module 8.5 (JSCAD array loops) uses throughout, and the exact non-mutating shape confirmed by the ch3 usage audit's `.push()`/`.map()` downstream check.
