# Module 5.2: Physics Feel

**Quarter 2 · Environment: moSHion canvas**

## SLO Focus
- Reinforces **SLO-3** (program design tools and environments) through
  tuning: change one property, run it, judge the result.

## Module Goal
Students give a sprite a physical character: gravity, bounce, friction :
and learn that these are dials to be tuned by running the thing, not values
to be calculated.

## Pre-requisite snapshot
Module 5.1 (Hello Sprite and Movement) complete. Students can create a
canvas, make a sprite and set its velocity.

## Post-requisite snapshot
Students can build a closed physical space, drop a body into it, and adjust
gravity, bounciness and friction to get a feel they chose deliberately.
