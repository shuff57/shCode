# Module 6.8: Joints

**Quarter 2 · ~1.5 contact hours**
**Environment:** moSHion in-app editor.

## Module Goal
Students connect two sprites with a joint, choose between a distance and a hinge
joint, remove a joint cleanly, and then compose all three with a directional
impulse into the slingshot pattern — which is what book §6.8.6 (Impulses and the
Slingshot Pattern) closes the section on. Most students won't fully master joints;
aim for "understand enough to pick one for the capstone." `SliderJoint` is
challenge-only.

## Inter-module bridges
- **Unit 6.7 → 6.8:** the slingshot is drag (6.7.9, 6.7.10) plus hit-testing
  (6.7.6) plus a joint plus a release impulse. It cannot be taught before 6.7.
- **Unit 6.6 → 6.8:** Pong-Sumo is structured with the state machine from 6.6
  (title → play → win → reset).
- **Unit 6.8 → 7.1 (Capstone):** this is the last content unit; students draft a
  capstone design doc as evening homework, due Day 1 of Unit 7.1.

## Pre-requisite snapshot
Module 6.7 (Advanced Input) complete. `applyForce` was introduced in 5.2 and 6.3;
this unit is where it is taught as an aimed impulse.

## Post-requisite snapshot
- Can create a `DistanceJoint` and a `HingeJoint`, and remove a joint at runtime.
- Can build a pendulum and a rotating arm.
- Can apply a directional impulse with `applyForce` using a vector from sprite A
  to sprite B.
- Has implemented the slingshot pattern (joint + drag + release + force).
- Has shipped a two-player game with separate input schemes, tuned push-collision
  (`bounciness`), state-machine flow, and at least one joint.
- Has a 1–2 page capstone design doc in hand for Day 1 of Unit 7.1.

## Unit-level assessments
A17.1 Pong-Sumo (6.8.14). No unit quiz; the capstone (A18.1) begins in Unit 7.1.
