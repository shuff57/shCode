# Module 3.5: Objects and Properties

## Module Goal
Students group related values in an object, read and change properties by dot or bracket, work with nested objects, attach methods, and destructure fields out of an object.

## Pre-requisite snapshot
Module 3.4 (Function Expressions and Arrow Functions) complete.

## Post-requisite snapshot
Students can model a record as an object and pull fields out of it by destructuring — the shape Module 5.3 (Classes and Objects via moSHion) builds instances on, and the pattern that closes the object-literal/property-access gap the original 2026-08-07 audit flagged (140/133 downstream uses against 6/12 taught).
