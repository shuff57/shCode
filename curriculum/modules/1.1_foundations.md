# Module 1.1 — Foundations

**Quarter 1 · Week 1 · Environment: browser DevTools console**

## SLO Focus
- **Introduces SLO-1** (software life-cycle) — primary artifact A1.1.
- Reinforces **SLO-4** (process as algorithm).

## Module Goal
Students understand what programming is and where it sits in a software
project's lifecycle: the four framework activities, the umbrella activities
that run alongside them, task sets, SDLC methodologies and the four Ps, and
how to judge whether a prescriptive process model fits a given project.

## Pre-requisite snapshot
None. First module of the course.

## Post-requisite snapshot
Can name the four framework activities and classify a task into the correct
one; can name umbrella activities; can write a task set; can explain SDLC
methodologies and the four Ps; can judge whether a prescriptive process
model fits a given project; can open the browser console and run
`console.log`.

### What the resequence fixed

1. **The unit quiz sat at position 7 of 23**, assessing material taught in
   lessons 8–21. It is now last.
2. **A1.1.1 (the SDLC writeup) sat at position 3**, before the Four Phases
   reading that teaches what it asks for. It now follows that reading and
   its worked example.
3. **The two console labs were inverted.** `1-1-6-first-statement` (run five

### JS basics here are shCode's own — the book has none

`1-1-2-reading-console-log` and `1-1-4-sdlc-overview` teach `console.log`,
strings, booleans and sequential execution. **Book §1.1 contains none of
this** — it is purely the software lifecycle (zero occurrences of boolean,
integer, string or sequential; `console.log` appears only inside two worked
examples). This material is deliberate week-one scaffolding so day one has
something runnable, per `curriculum-plan.md` §1.1's in-class activities.

Two consequences. **A resync must not delete these as "not in the book".**
And the §1.1 deck cannot cover them, so a teacher presenting from slides
alone will reach the console labs having introduced no JavaScript — logged
as a book-side gap in `BOOK-TO-MODULE.md` §8.
