# Unit 1.1 — Foundations

**Quarter 1 · Weeks 1–3 · ~10.5 contact hours**
**Environment:** Browser DevTools console (no install).

## SLO Focus
- **Introduces SLO 1** (software life-cycle) — W1 primary artifact A1.1
- **Introduces SLO 2** (coding conventions and structured style foundations)

## Unit Goal
Students understand what programming *is*, can run their first JavaScript statements in the DevTools console, know the vocabulary of variables / types / expressions / sequential processing, and write code that follows the class style guide from day one.

## Modules in this unit

| ID | Week | Title | Primary SLO | Key Artifact |
|----|------|-------|-------------|--------------|
| [1.1.1](modules/1.1.1_software-lifecycle.md) | 1 | What Is Programming / Software Lifecycle | SLO 1 | A1.1 written |
| [1.1.2](modules/1.1.2_variables-and-types.md) | 2 | Variables and Data Types | SLO 2 (intro) | A2.1, A2.2 labs |
| [1.1.3](modules/1.1.3_documentation.md) | 3 | Documentation and Coding Conventions | SLO 2 | A3.1 lab, A3.2 written, A3.3 quiz |

## Inter-module bridges
- **1.1.1 → 1.1.2:** The `console.log` habit from W1 is the delivery mechanism for all W2 variable-output examples.
- **1.1.2 → 1.1.3:** The naming conventions teased in W2 are formalized in W3 as the class style guide.
- **Unit 1.1 → Unit 1.2:** Variables + documentation are prerequisites for Conditionals (W4).

## Pre-requisite snapshot (student knowledge entering this unit)
None. First unit of the course.

## Post-requisite snapshot (what students have after this unit)
- Can open browser DevTools, run JS statements, and screenshot output.
- Can declare variables with `let`/`const`, use 4 primitive types, write string expressions.
- Can write inline + JSDoc-style comments and follow the distributed style guide.
- Understands the SDLC phases vocabulary.

## Unit-level assessments
- **A3.3 Quiz (W3)** — in-class, closes the unit with a short vocabulary + syntax check.
- Ongoing: style guide compliance graded on every subsequent lab.
