# Module 2.2 — Algorithms and Loops

**Quarter 1 · Week 5 · Environment: browser DevTools console**

## SLO Focus
- **Introduces SLO 4** (algorithms) — primary written artifact A5.1.

## Module Goal
Students define what an algorithm is and repeat work with loops: `for`, `while`, and `do…while`; loop tracing and avoiding infinite loops.

## Pre-requisite snapshot
Module 2.1 (Conditionals) complete.

## Post-requisite snapshot
Students can trace and write `for`/`while`/`do…while` loops and state precisely what an algorithm is.
