# Module 2.2: Algorithms and Loops

**Quarter 1 · Week 6 · Meets Mon Sep 14, 2026 · Environment: browser DevTools console**

## SLO Focus
- **Introduces SLO 4** (algorithms): primary artifact **A2.2.1** (Written + Lab), gated by the **A2.2.0** flowchart.
- Reinforces SLO 3 (`for`, `while`, `do…while`).

## Module Goal
Students define what an algorithm is, see that a program is an algorithm written
in a language a computer can run, and repeat work with loops: `for`, `while`,
and `do…while`. They trace loops to predict output, avoid infinite loops, use
a step other than 1, and meet the idea of a canonical algorithm (linear search)
without yet having arrays or `break` to write the full version.

20 lessons: 16 shipped in the 2026-08-15 diagram-native pilot, plus 4 added in
this pass to close book-coverage gaps (§Note below).

## Pre-requisite snapshot
Module 2.1 (Conditionals) complete.

## Post-requisite snapshot
Students can trace and write `for`/`while`/`do…while` loops, state precisely
what an algorithm is and how a program differs from one, use a `for` loop with
a step other than 1, and describe what a canonical algorithm is.
