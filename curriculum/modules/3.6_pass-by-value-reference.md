# Module 3.6: Functions: Pass by Value/Reference

## Module Goal
Students explain why changing a number inside a function leaves the original alone while changing an array does not, and copy defensively when it matters.

## Pre-requisite snapshot
Module 3.5 (Objects and Properties) complete.

## Post-requisite snapshot
Students can predict whether a function call will alter the caller's data.
