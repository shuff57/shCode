# Module 4.1 — Synthesis

**Quarter 1 · Week 9 · Environment: browser DevTools console**

## SLO Focus
- **SLO 3 backup artifact (A9.1 Print Job Manager)** — the first complete design / implement / test program.
- Reinforces SLO 1, 2, and 4 in a single cohesive project.

## Unit Goal
Students pull together everything from Q1 — variables, conditionals, loops, functions, and arrays — into one documented, tested program, and reflect on how they built it.

## Lessons in this unit
- **Plan before you code** — turn a task into steps before writing code.
- **Manual testing** — call a function with a known input and check it against an expected result (PASS / FAIL).
- **Print Job Manager (mini-project)** — the Q1 capstone: store jobs as objects in an array, write functions to process them, and test the key logic.
- **Q1 Reflection** — reflect on the quarter and connect the build to the software-development life-cycle (SLO 1).

## Pre-requisite snapshot
Units 1.1–1.3 complete — variables, conditionals, loops, functions, and arrays.

## Post-requisite snapshot
Students have shipped one complete, documented, manually-tested program and can describe the design → implement → test process they followed.
