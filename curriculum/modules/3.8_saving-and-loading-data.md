# Module 3.8: Saving and Loading Data

## Module Goal
Students save a value to text with `JSON.stringify`, restore it with `JSON.parse`, handle a parse failure, and persist state by key across a session.

## Pre-requisite snapshot
Module 3.7 (Array Methods) complete.

## Post-requisite snapshot
Students can persist a small piece of state across a reload — the pattern Module 6.5 (Save and Load) builds games on, and the reason §3.8 exists at all (the original 2026-08-07 audit found `JSON.parse` used 11 times downstream, `JSON.stringify` 3 times, and key-value storage 3 times, none taught anywhere before this section).
