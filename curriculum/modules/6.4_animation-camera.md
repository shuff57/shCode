# Module 6.4 — Animation & Camera

**Quarter 2 · Week 15 · ~3.5 contact hours**
**Environment:** shplay in-app editor.

## SLO Focus
- Reinforces **SLO 3** (implement + test polished systems needed for the capstone)

## Unit Goal
Students add the two things that visually separate "my first q5 sketch" from "this looks like a real game": animated sprites and a camera that follows the player. By end of W15 their games feel scaled — the world no longer ends at canvas edge.

## Inter-module bridges
- **Unit 2.3 → 2.4.1:** Groups are used for platforms; platformer challenge needs groups + physics + animation together.
- **Module 6.4 → Unit 2.5:** The "game loop has a scene larger than the canvas" framing sets up the need for game states (menu vs play vs win/lose) in W16.

## Pre-requisite snapshot
- Can create and iterate over groups (2.3.1).
- Comfortable with physics and input (2.1–2.3).

## Post-requisite snapshot
- Can attach multiple animations to a sprite and switch between them.
- Can implement a camera-follow pattern using `camera.x = player.x - canvas.w/2`.
- Has shipped a scrolling platformer with a visible end goal.
