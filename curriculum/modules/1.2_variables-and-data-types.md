# Module 1.2 — Variables and Data Types

**Quarter 1 · Week 2 · Environment: browser DevTools console**

## SLO Focus
- Reinforces **SLO-1**; introduces **SLO-2** (structured, conventional code).

## Module Goal
Students declare variables with `let`/`const`, name the eight data types and
give an example of each, explain what "dynamically typed" means, use `typeof`
to check what a value actually is, and tell `null` from `undefined`.

## Pre-requisite snapshot
Module 1.1 (Foundations) complete.

## Post-requisite snapshot
Students can declare variables, name and recognise every type in the
language, check a value's type at runtime, and write a description sentence
with a template literal.

## Note
Book §1.2 Variables and Data Types (568 lines). Ships as a 30-lesson
sequence, matching module 1.1's density (23 lessons over 253 book lines).

### Two blocks, and why the numbering runs the way it does

**1.2.1 – 1.2.6 (built earlier)** are the plan-derived block: slides,
`let`/`const`, string methods, operators and coercion, and two labs. These
cover ground `curriculum-plan.md` assigns to §1.2 that the book itself does
not teach here.

**1.2.7 – 1.2.30 (built 2026-08-16)** are the book-derived block, 1:1 against
book §1.2's eight subsections plus its intro and summary.

The book block was **appended rather than interleaved**, and that was forced:
`1-2-1-slides`, `1-2-5-lab-variables-types-check` and
`1-2-6-lab-operators-check` carry live student progress in D1 (1, 10 and 8
`lesson_state` rows respectively, plus 2 commits across the module).
`lesson_state.lesson_id` is the folder name, so renumbering any of them
orphans real work — see `BOOK-TO-MODULE.md` §7.3. The reading order still
works: 1.2.1–1.2.6 teach declaring and manipulating values, and 1.2.7 onward
opens with "every value you have been using has a type, and there are exactly
eight of them."

### Authoring notes

- **`symbol` is named but not taught.** The book introduces it in §1.2.7 and
  defers it to the objects chapter; 1.2.23 does the same.
- **`typeof null` is taught as a bug, twice** — once in passing at 1.2.20 and
  once properly at 1.2.25 — because it is the single most common way a
  beginner's type check goes wrong.
- **Nothing here teaches conditionals.** 1.2.19's comparisons produce
  booleans and stop there; `if` belongs to §2.1.
- The AP CSP binary-numbers discussion in `curriculum-plan.md` §1.2 has a
  worksheet at `curriculum/resources/1.1.2_binary-worksheet.md` and no lesson
  slot. It is a teacher-led in-class activity, deliberately not in-app.
