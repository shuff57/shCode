# Module 1.2 — Variables and Data Types

**Quarter 1 · Week 2 · Environment: browser DevTools console**

## SLO Focus
- Reinforces **SLO-1**.

## Module Goal
Students declare variables with `let`/`const`, work with the primitive types (numbers, strings, booleans), use string methods, and understand arithmetic operators and type coercion.

## Pre-requisite snapshot
Module 1.1 (Foundations) complete.

## Post-requisite snapshot
Students can declare variables, use the primitive types, and write expressions with correct operator/coercion behavior.
