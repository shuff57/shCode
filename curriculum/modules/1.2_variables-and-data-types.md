# Module 1.2 — Variables and Data Types

**Quarter 1 · Week 2 · Environment: browser DevTools console**

## SLO Focus
- Reinforces **SLO-1**; introduces **SLO-2** (structured, conventional code).

## Module Goal
Students declare variables with `let`/`const`, name the eight data types and
give an example of each, explain what "dynamically typed" means, use `typeof`
to check what a value actually is, and tell `null` from `undefined`.

## Pre-requisite snapshot
Module 1.1 (Foundations) complete.

## Post-requisite snapshot
Students can declare variables, name and recognise every type in the
language, check a value's type at runtime, and write a description sentence
with a template literal.

## Note

sequence, matching module 1.1's density (23 lessons over 253 book lines).

**This fixed a real prerequisite violation.**
`1-2-26-lab-variables-types-check` has `typeof` in a graded requirement and
used to sit at position 5 — seventeen lessons before the `typeof` reading.
`1-2-5-lab-change-the-type` had the same problem at position 9.

`1-2-5` now follows the `typeof` reading, at 1.2.26. `1-2-9` stays beside the
dynamic-typing reading it demonstrates, at 1.2.5, and **hands the student the
single line of `typeof` it needs** in its own step instructions — the way
`1-1-4-sdlc-overview` teaches `console.log`. That mirrors the book, which uses
`typeof` in its §1.2.5 and §1.2.6 Try It Nows and only defines it at §1.2.8.

### ⚠ Folder numbers do NOT match title numbers in this module

Reordered **by title only.** Order comes from the number in
`lesson.json.title`; student progress hangs off the folder name via
`lesson_state.lesson_id`. `1-2-1-slides`, `1-2-26-lab-variables-types-check`
and `1-2-16-lab-operators-check` carry 19 progress rows between them, so every
folder name was left exactly as it was.

**Do not "tidy" the folder names to match the titles** — renaming a folder
orphans real student work. See `BOOK-TO-MODULE.md` §7.3.

### Authoring notes

- **`symbol` is named but not taught.** The book introduces it in §1.2.7 and
  defers it to the objects chapter; 1.2.22 does the same.
- **`typeof null` is taught as a bug, twice** — once in passing at 1.2.19 and
  once properly at 1.2.24 — because it is the single most common way a
  beginner's type check goes wrong.
- **Nothing here teaches conditionals.** 1.2.18's comparisons produce
  booleans and stop there; `if` belongs to §2.1.
- **1.2.5 is the one lesson that runs ahead of its material**, and does so
  deliberately. It needs `typeof`, which the book keeps for its last
  subsection, so the lab teaches the single line it needs in its own step
  instructions and points forward to 1.2.23. The alternative — moving it to
  position 26 — was tried and reverted: it landed as the third `typeof` drill
  in a row and stopped demonstrating dynamic typing at all.
- The AP CSP binary-numbers discussion in `curriculum-plan.md` §1.2 has a
  worksheet at `curriculum/resources/1.1.2_binary-worksheet.md` and no lesson
  slot. It is a teacher-led in-class activity, deliberately not in-app.
