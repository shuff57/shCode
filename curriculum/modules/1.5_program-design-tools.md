# Module 1.5 — Program Design Tools and Environments

**Quarter 1 · Weeks 5–6 · Environment: browser DevTools console**

## SLO Focus
- **Introduces SLO-3** (program design tools and environments) — this is that
  topic's primary coverage in Butte's official outline.

## Module Goal
Students plan before they type: name the four techniques of computational
thinking, pseudocode a task in structured English, read and draw a flowchart
that passes the class convention, run JavaScript in the console and an
editor, read an error message, and find a silent bug with `console.log`.

## Pre-requisite snapshot
Module 1.4 (Programming Paradigms and Languages) complete.

## Post-requisite snapshot
Students can produce a flowchart that passes all structural checks, turn it
into working JavaScript, and debug a program that produces a wrong answer
without erroring. From here on **every** graded build artifact opens with a
flowchart, and the coding half stays locked until the chart is green.

## Note
Book §1.5 Program Design Tools and Environments (983 lines — the largest
section in Chapter 1, scheduled at **two meetings**). Ships as a 44-lesson
sequence, 1:1 against the book's nine subsections.

**The class flowchart convention (Appendix D) is handed out here**, exactly
as the style guide is handed out in §1.3, and is enforced on every graded
build artifact from this point forward. Only four shapes exist this week —
the book's oval, rectangle and diamond, plus the parallelogram, which is
ours. The editor hides four more behind **+ more shapes**: the loop hexagon
arrives at §2.2, the function-call shape at §3.1, connectors and notes at
§4.1. Tell students they exist and to leave them alone — a student who finds
them early will use a hexagon as decoration.

### Authoring notes

- **Recursion (1.5.33–1.5.34) is a preview, not a requirement.** The book
  teaches it here with a JS function; functions arrive in §3.1. Students read
  and run it; nothing asks them to write one.
- **1.5.34 uses `try`/`catch`** solely so the stack-overflow message prints
  tidily instead of halting the page. It is flagged in the lesson as
  something to ignore for now.
- **1.5.31 has no "write the pseudocode first" grader check.** A regex cannot
  distinguish a student's plan comments from the starter's instructions, and
  a check that passes on an untouched file is worse than no check. The
  pseudocode requirement is graded properly at 1.5.24 instead.
