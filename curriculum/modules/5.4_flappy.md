# Module 5.4: Project — Flappy

**Quarter 2 · the second build · after §5.3 Pinball**

## SLO Focus
- **SLO 3:** the module's artifact is a complete, playable game.
- Reinforces **SLO 2** and **SLO 4**.

## Module Goal
Students build a flapping-bird game with functions, variables, arrays and sprite properties. The new idea is a world that scrolls: obstacles are built on a timer, kept in an array, and deleted when they leave. **No classes anywhere in this module.**

## Pre-requisite snapshot
§5.3 complete: the state flag, the edge-versus-level pattern for a score, and the restart that puts back everything a round owns. Arrays from 3.3.

## Post-requisite snapshot
Can build, track and remove a changing set of sprites, and can say what a restart has to put back. Ready for §5.5, the third build.

## Note
**Not a book section, and no classes.** Second of the three functional game builds (5.3–5.5). The array is injected where the game needs it (5.4.4), not taught up front, following the CodeHS rollout described in `CODEHS-SEEDING.md`.

**9 lessons** (`5.4.1`–`5.4.9`) in folders `5-4-flappy-*`.

### The one idea this module is really about
A game with many things alive at once has to keep track of them: build them, find them again, and delete them in two places (the screen and the array). 5.4.4–5.4.5 build the lesson around the backwards `splice` loop.

## Unit-level assessments
5.4.8 is a short check, following the CSP habit of closing a content module with one quiz. 5.4.9 closes on challenges.
