# Module 5.3: Classes and Instances

**Quarter 2 · ~1.75 contact hours (combined week with §5.4, see that module's Note)**
**Environment:** moSHion in-app editor.

## SLO Focus
- **SLO 2 (intro)**: first formal exposure to class vs. instance, ahead of §5.4's SLO 2 primary artifact
- Reinforces **SLO 3**

## Module Goal
Students formally understand what a class is, after two weeks of quietly using `new Sprite(...)`. They can distinguish a class (blueprint) from its instances (objects), and explain a property as data belonging to one instance vs. the class's own default.

## Pre-requisite snapshot
- Comfortable with `new Sprite()`, `sprite.color = ...`, and dot access in general (Module 5.1).
- Has seen functions (Q1) and understands parameter passing.

## Post-requisite snapshot
- Can explain the class/instance distinction using sprites already built in §5.1–§5.2 as the running example.
- Ready for §5.4, which has the student write their own class instead of just using pre-built ones.

## Unit-level assessments
No graded assignment of its own: §5.3's content (class vs. instance, properties) builds
directly into §5.4, where the graded Collectible lab (A5.4.1) and OOP written comparison
(A5.4.2, SLO 2 primary evidence) live. No unit-closing quiz: Midterm 3 covers Units
5.1–5.3/5.4 together at the end of Q2's moSHion block.
