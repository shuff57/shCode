# Module 6.9: Grids and Tile Maps

**Quarter 2 · Week 16 · after §6.8 Joints**

## SLO Focus
- **SLO 3:** the module's artifacts are a playable game (the Coin Maze) and a clickable grid (lights, then a wall of bricks).
- Reinforces **SLO 4:** scanning and indexing a grid are algorithms and data structures.

## Module Goal
Students build a maze whose levels are rows of text, read a map as data, and keep a grid of cells in an array of arrays that the screen is drawn from. The new ideas are the map, the pixel and cell conversion and the offset, and bounds.

## Pre-requisite snapshot
§6.1-6.8 complete: groups and overlaps, the mouse, nested arrays from 3.3.20, nested loops from 2.4.

## Post-requisite snapshot
Can write a level as text and build it with `Tiles`, find a letter and convert between pixels and cells, and build, draw, click and count a grid of arrays. Has a brick wall with `hitAt(x, y)` ready for a Breakout ball.

## Note
**Not a book section.** 14 lessons (`6.9.1`-`6.9.14`) in folders `6-9-grids-*`. The folder prefix is kept when the module is renumbered into the systems block after 6.1 (`codehs-review/PLACEMENT.md` item 12); only the displayed `6.9.N` moves.

- **Words on screen go in `drawTop()`**, the convention 5.4 set.
- **The maze is top-down on purpose.** No gravity, no jumping, so every new idea is about the map.
- **The brick wall is `rect`s, not sprites, on purpose.** `Tiles` makes a sprite per tile and moSHion tests every sprite pair each frame; a wall of rects costs nothing, and a Breakout module can turn the data into sprites later.
- **`P` is deliberately not in the legend.** `Tiles` treats it as an empty cell, so the student has to find the start by scanning the text (6.9.5-6.9.6).

### The one idea this module is really about
*A grid is data and the picture is drawn from it.* The maze map is read-only text that `Tiles` turns into sprites; the lights and bricks are arrays of arrays you change. The only place pixels and cells meet is two small conversions: `c * TILE + TILE / 2` and `floor(x / TILE)`.
