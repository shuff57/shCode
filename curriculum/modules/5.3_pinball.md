# Module 5.3: Project — Pinball

**Quarter 2 · the first build · after §5.2 Physics Feel**

## SLO Focus
- **SLO 3:** the module's artifact is a complete, playable game built from the physics the previous two modules taught.
- Reinforces **SLO 2** and **SLO 4**.

## Module Goal
Students plan, then take the pinball scene they already built in 5.2.18 and turn it into a game: something to aim at, a score that counts an event rather than a frame, a way to lose, and a way to start again, then playtest and reflect on it. Everything is built with functions, variables and sprite properties — **no classes anywhere in this module**.

## Pre-requisite snapshot
§5.2 complete: gravity, static bodies, `colliding()`, edge- versus level-triggered input, bounciness and friction, `applyForce`, and the pinball scene at 5.2.18.

## Post-requisite snapshot
Can build a small complete game from parts, and can say what a score is counting. Ready for §5.4, the second build.

### The one idea this module is really about
A collision is not an event. `colliding()` is true on every frame two sprites touch, so `if (ball.colliding(bumper)) score += 1` adds sixty points a second. The fix — remember whether you were touching *last* frame — is the same edge-versus-level distinction 5.2.9 taught for keys, one layer down. 5.3.5–5.3.8 build the whole lesson around it.
