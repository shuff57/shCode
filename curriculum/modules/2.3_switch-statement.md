# Module 2.3: The Switch Statement

**Quarter 1 · Week 6 (Wed Sep 16, 2026) · Environment: browser DevTools console**

## SLO Focus
- Reinforces **SLO 3**.

## Module Goal
Students can write a `switch` statement with `case`/`default`/`break`, explain
and avoid the fall-through and strict-equality traps, group cases that share
an outcome, and choose correctly between `switch` and an `if...else` chain.

## Pre-requisite snapshot
Module 2.1 (Conditionals) and Module 2.2 (Algorithms and Loops) complete.
`break` is taught here as a `switch`-exit keyword only: **not** as loop
control, which is Module 2.4's job. No try/catch, no functions, no arrays.

## Post-requisite snapshot
Students can convert between if-chains and switch statements, predict and fix
fall-through bugs, and know why `switch` never matches a value of the wrong
type. Module 2.4 (Loop Control and Nested Loops) reuses `break`, this time as
a loop-exit: flag the difference explicitly when it's re-taught there.
