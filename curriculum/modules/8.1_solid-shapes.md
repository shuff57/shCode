# Module 8.1: Solid Shapes

**Quarter 3 · first reSHape module**
**Environment:** reSHape in-app modeller (B-rep kernel), Build side first, then reSHape Script.

## Unit Goal
Students make their first solid part by hand, discover that the part is a list
of steps they can go back and change, then read and finally write those steps
as a program. One new idea per lesson.

## Lessons in this module

| ID | Title | Mode | One idea |
|----|-------|------|----------|
| 8.1.1 | Reading: A Part Is a List of Steps | reading | a model is a recipe of steps; mm; Build vs Code |
| 8.1.2 | Lab: Your First Box | visual | Box tool, typing sizes |
| 8.1.3 | Lab: Change Your Mind | visual | re-select an earlier step and change a number |
| 8.1.4 | Lab: Drill a Hole | visual | Hole on a face, Across |
| 8.1.5 | Lab: Round an Edge | visual | pick an edge, Round |
| 8.1.6 | Lab: Hollow It Out | visual | Hollow, wall, open face |
| 8.1.7 | Reading: Build Wrote a Program | reading | the script is the timeline as text |
| 8.1.8 | Lab: Read the Script | both | change one number in the text |
| 8.1.9 | Lab: Write It Yourself | code | write box + hole from breadcrumbs |
| 8.1.10 | Lab: Sketch and Pull | visual | Rectangle sketch, then Pull |
| 8.1.11 | Project: Desk Tray | both | box + hollow + round, together |

## Inter-module bridges
- **Modules 1.x → 8.1.8/8.1.9:** variables and function calls carry straight
  over; `const b = box(40, 40, 20)` is a call the student has read a hundred of.
- **Module 8.1 → later reSHape modules:** sketches, patterns, parameters.

## Pre-requisite snapshot
- Units 1-4 (JavaScript fundamentals). No prior CAD.

## Post-requisite snapshot
- Student has built, edited, drilled, rounded and hollowed a part by hand.
- Student can read a reSHape Script and change it, and write a two-line one.
