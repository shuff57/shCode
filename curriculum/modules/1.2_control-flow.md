# Unit 1.2 — Control Flow

**Quarter 1 · Weeks 4–6 · Environment: browser DevTools console**

## SLO Focus
- **Introduces SLO 4** (algorithms) — W5, primary written artifact A5.1.
- **Reinforces SLO 3** — students implement their first structured programs with branching and iteration.

## Unit Goal
Students can make decisions in code (conditionals), define what an algorithm is, and repeat work with loops — the building blocks of every program that does more than run top to bottom.

## Lessons in this unit
- **Conditionals** — `if` / `else if` / `else`, comparison operators (`===` vs `==`), logical operators (`&& || !`), and `switch`.
- **Algorithms** — what an algorithm is and why precise, ordered steps matter (SLO 4).
- **Loops** — `for`, `while`, and `do…while`; loop tracing and avoiding infinite loops.

Readings introduce one concept at a time with runnable console examples; the console practice lessons and the plain-English algorithm writeup put them to work.

## Pre-requisite snapshot
Unit 1.1 complete — students can declare variables, use the four primitive types, and write expressions.

## Post-requisite snapshot
Students can branch with conditionals, trace and write `for`/`while`/`do…while` loops, and state precisely what an algorithm is.
