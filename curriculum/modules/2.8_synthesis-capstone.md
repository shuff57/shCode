**Quarter 2 · ~3.5 contact hours in class + homework**
**Environment:** shplay in-app editor.

> **Renumber note:** Was Unit 2.7 before Unit 2.5 was split into 2.5 (Game Saves) and 2.6 (Game States). Cascaded to 2.8.

## SLO Focus
- **SLO 3 PRIMARY Sem 1 evidence (A18.1 Game Capstone)** — design + implement + test cycle

## Unit Goal
Students ship a complete game that they designed themselves. The unit is entirely build + test + iterate + showcase. This is the Semester 1 closing artifact — the teacher retains design docs, testing logs, and reflections for dual-enrollment documentation.

- All of Q2 content (Units 2.1–2.7).

- Student has shipped a working game.

- Teacher's SLO 3 evidence folder contains the A18.1 artifact.
