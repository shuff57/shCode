# Unit 2.7 — Synthesis (Game Capstone)

**Quarter 2 · Week 18 · ~3.5 contact hours in class + homework**
**Environment:** q5play in-app editor.

## SLO Focus
- **SLO 3 PRIMARY Sem 1 evidence (A18.1 Game Capstone)** — design + implement + test cycle
- Contributes to **SLO 1** (lived SDLC)
- Contributes to **SLO 2** (classes + state machines in a shipped product)

## Unit Goal
Students ship a complete game that they designed themselves. Week 18 is entirely build + test + iterate + showcase. This is the Semester 1 closing artifact — the teacher retains design docs, testing logs, and reflections for dual-enrollment documentation.

## Inter-module bridges
- **Unit 2.1–2.6 → 2.7.1:** Every prior q5play unit contributes directly. The capstone rubric *requires* a custom class (2.2), a Group (2.3), persistent storage (2.5), and multiple game states (2.5).
- **Unit 2.7 → Sem 2 (Q3):** None — clean quarter break. Semester 2 starts with a fresh environment (JSCAD).

## Pre-requisite snapshot
- All of Q2 content (W10–W17).
- A capstone design doc drafted as W17 evening homework.

## Post-requisite snapshot
- Student has shipped a working game.
- Student has written design doc, testing log, and 1-page SDLC reflection.
- Student has presented a 3-minute showcase to the class.
- Teacher's SLO 3 evidence folder contains the A18.1 artifact.

## Unit-level assessments
- **A18.1 Capstone Game (major grade — 15% of course total).**
- **Semester 1 Final exam (scheduled same week, separate day):** 1.5 hour cumulative W1–W18 covering JS fundamentals + q5play + OOP.
