# Module 2.6.1 — Joints and Advanced Input

> **Week 17 · Q2 Advanced Mechanics · 3.5 contact hours (2 sessions) · Environment: q5play in-app editor**
> **SLO focus:** Reinforces SLO 3. Final content week before the capstone.

## Context

Week 17 introduces the most expressive physics mechanics q5play offers — **joints** (distance, hinge, slider), **mouse input** (drag + release), and **multi-player input** (separate key schemes per player). Most students won't master joints fully in one week — aim for "understand enough to use in capstone." The W17 evening homework is the capstone design doc draft.

**Do NOT:**
- Require all three joint types — pick distance + hinge as core; slider is stretch.
- Extend the capstone window into W17 — keep W17 focused on joints content.

---

## Learning Objectives

Students will be able to:
1. Create distance, hinge, and slider joints between sprites.
2. Implement a slingshot pattern: drag, release, apply force.
3. Handle two-player input with separate key bindings.
4. Debug joint behavior by adjusting constraint parameters.

## Topics Covered
- `new DistanceJoint(a, b, ...)` — fixed-length connection.
- `new HingeJoint(a, b, ...)` — rotational pivot.
- `new SliderJoint(a, b, ...)` — linear track.
- Mouse input: `mouse.pressing()`, `mouse.pressed()`, `mouse.x/y`.
- Applied force on release: `sprite.applyForce(fx, fy)`.
- Two-player key mapping strategies.

- All of Units 2.1–2.5 complete.
- Capstone design doc homework assigned end of W17.

## Worked Examples

### Worked Example 1 — Distance joint (5 min)
```js
let a, b, joint;

function setup() {
  new Canvas(400, 400);
  world.gravity.y = 5;
  a = new Sprite(200, 50, 30, 30);
  a.collider = 'static';
  b = new Sprite(300, 50, 20, 20);
  joint = new DistanceJoint(a, b);
}

function draw() {
  background('#222');
}
```
Run. `b` swings under `a` like a pendulum. Now you've recreated W14's pendulum worked example in 10 lines.

### Worked Example 2 — Hinge joint (rotating arm, 5 min)
```js
let pivot = new Sprite(200, 200, 10, 10);
pivot.collider = 'static';
let arm = new Sprite(260, 200, 120, 20);
new HingeJoint(pivot, arm, { anchor: pivot.pos });
```

### Worked Example 3 — Slingshot pattern (15 min)
```js
let ball, anchor, joint, dragging = false;

function setup() {
  new Canvas(500, 400);
  world.gravity.y = 10;
  anchor = new Sprite(100, 300, 10, 10);
  anchor.collider = 'static';
  ball = new Sprite(100, 300, 20, 20);
  joint = new DistanceJoint(anchor, ball, { length: 0 });  // rest at anchor
}

function draw() {
  background('#222');
  // Drag: grab the ball with the mouse
  if (mouse.pressing() && ball.overlaps({ pos: { x: mouse.x, y: mouse.y } })) dragging = true;
  if (dragging) {
    ball.pos.x = mouse.x;
    ball.pos.y = mouse.y;
    ball.vel.x = 0; ball.vel.y = 0;
  }
  // Release: remove joint, apply launch force
  if (!mouse.pressing() && dragging) {
    dragging = false;
    let dx = anchor.pos.x - ball.pos.x;
    let dy = anchor.pos.y - ball.pos.y;
    joint.remove();
    ball.applyForce(dx * 5, dy * 5);
  }
}
```

### Worked Example 4 — Two-player input (5 min)
```js
// Player 1: WASD
if (kb.pressing('w')) p1.vel.y = -3;
if (kb.pressing('a')) p1.vel.x = -3;
if (kb.pressing('s')) p1.vel.y = 3;
if (kb.pressing('d')) p1.vel.x = 3;

// Player 2: arrows
if (kb.pressing('up'))    p2.vel.y = -3;
if (kb.pressing('left'))  p2.vel.x = -3;
if (kb.pressing('down'))  p2.vel.y = 3;
if (kb.pressing('right')) p2.vel.x = 3;
```

## Assignments

### A17.1 — Two-Player Pong-Sumo
**SLO 3 primary**

| | |
|---|---|
| Type | Lab (in-app editor — `q5play-sumo-challenge` lesson) |
| Points | 20 |
| Est. time | 75 min |
| Due | End of Week 17 |

**Requirements:**
- **Two player-controlled sprites** with separate input schemes (e.g., WASD vs arrows).
- **Physics-based collisions** push players around (not manually coded collisions — let Box2D handle it).
- **Win condition:** when one sprite is knocked out of bounds (off-canvas or off a central platform), the other wins.
- **Visible score or round counter** displayed during play.
- At least one joint or constraint used somewhere (can be a static ring boundary using a DistanceJoint chain, or a moving obstacle).
- Game returns to a "ready" state after a win, allowing a replay.

**Rubric (20 pts):**
| Criterion | Pts |
|-----------|-----|
| Two player inputs work independently | 4 |
| Physics-based push-collision feels right | 4 |
| Win condition triggers cleanly | 4 |
| Score/round counter visible | 2 |
| At least one joint used | 2 |
| Replay / reset flow works | 2 |
| Code + style guide | 2 |

## Vocabulary

| Term | Definition |
|------|-----------|
| **Joint** | A constraint linking two sprites |
| **Distance joint** | Fixed-length tether (like a rope or rod) |
| **Hinge joint** | A rotational pivot (like a door hinge) |
| **Slider joint** | A linear track (like a drawer) |
| **Anchor** | The fixed point around which a joint pivots |
| **Impulse** | A one-frame force application |
