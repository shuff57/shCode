# Unit 1.3 — Functions and Data

**Quarter 1 · Weeks 7–8 · Environment: browser DevTools console**

## SLO Focus
- **Reinforces SLO 2** (functions as structured decomposition) and **SLO 3** (design/implement routines).
- Covers the Butte outline topic **pass by value/reference** (W7, written artifact A7.2).

## Unit Goal
Students can package code into reusable functions with parameters and return values, reason about scope and how JavaScript passes values, and store/process collections of data with arrays.

## Lessons in this unit
- **Functions** — defining vs calling, parameters and arguments, return values, and scope (local vs global).
- **Pass by value vs reference** — primitives are copied; objects and arrays are shared. Defensive copying with `[...]` / `{...}` (SLO 2 written artifact A7.2).
- **Arrays & data** — indexing, `push`/`pop`/`length`, looping with `for` and `for…of`, and splitting text into lines (`.split`) as a bridge to File I/O.

## Pre-requisite snapshot
Unit 1.2 complete — students can use conditionals and loops.

## Post-requisite snapshot
Students can write documented functions with parameters and returns, predict whether a function mutates its input, and build and iterate over arrays.
