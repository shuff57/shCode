# Module 5.4: Writing Your Own Classes

## Module Goal
Students write their own class with methods, hold sprites inside it by composition, and judge when a class earns its place over parallel variables.

## Pre-requisite snapshot
Module 5.3 (Classes and Instances) complete.

## Post-requisite snapshot
Students design and build a class of their own, and can argue for or against using one.

## Note
Book §5.4 Writing Your Own Classes. Currently **21 lessons**.

This module was split out of module 5.3, which covered both book sections under one number on 2026-08-16. The lessons were
already written and taught this material: they were simply numbered into a
neighbouring section, so the book's own section never appeared in the app.
Nothing was rewritten; the lessons were renumbered and their `unit` label
corrected.


### ⚠ Folder numbers do not match title numbers here

These lessons keep their original folder names, because `lesson_state.lesson_id`
is the folder name and renaming one orphans student progress. Order comes from
the number in `lesson.json.title`. See `BOOK-TO-MODULE.md` §7.3.
