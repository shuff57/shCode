# Module 5.5: Project — Snake

**Quarter 2 · the third build · after §5.4 Flappy**

## SLO Focus
- **SLO 3:** the module's artifact is a complete, playable game.
- Reinforces **SLO 2** and **SLO 4**.

## Module Goal
Students plan and build Snake on a grid. The new ideas are a world measured in cells, an array that grows at the front and shrinks at the back, and a search of that array. Everything is functions, variables, arrays and sprite properties: **no classes and no groups.**

## Pre-requisite snapshot
§5.4 complete: arrays of sprites, `frameCount` beats, the delete-and-splice pairing, the state flag and the restart that puts back everything a round owns.

## Post-requisite snapshot
Can plan a game as parts and remembered values, move and grow an array of sprites, search an array, and playtest. Ready for the class units (5.6 onward) and for 6.1's groups.

## Note
**Not a book section.** Third and last of the functional game builds (5.3-5.5). It is the first build with the **five-step close**: a written plan at the start (5.5.1) and a playtest-and-reflect at the end (5.5.9), both AI-graded, as decided 2026-10-30 (`codehs-review/PLACEMENT.md`). 5.3 and 5.4 gained the same close in a retrofit (5.3.1/5.3.11 and 5.4.1/5.4.9).

**11 lessons** (`5.5.1`-`5.5.11`) in folders `5-5-snake-*`. The `5-5-1`-`5-5-20` folders belong to what is now 5.8 and are still keyed in student progress, so this build takes its own prefix.

**Words on screen go in `drawTop()`** (round-4 review, 2026-10-30), the convention 5.4 set: in 5.5.4, 5.5.6, 5.5.8 and 5.5.11 the score, the key hint and Game over / press R are drawn in `drawTop()`, which runs after the sprites, because text drawn in `draw()` sat under the snake's cells when it crossed the top rows. 5.5.2 recalls it from 5.4.5 before the first lab.

### The one idea this module is really about
A body is an array, and moving it is not moving every cell: add one at the front, remove one at the back, and skip the removal when the snake eats. 5.5.5 teaches it and 5.5.7 reuses the same array for a search.

## Unit-level assessments
5.5.10 is a short check. 5.5.1 and 5.5.9 are the AI-graded plan and playtest, 0 points, and deliberately lenient like 5.4's: any answer that gestures at the question counts. 5.5.11 closes on challenges, graded by one card that any one of the three challenges turns green.
