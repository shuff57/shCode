# Module 3.1: Functions: Definition and Calls

**Quarter 1 · Week 7 · Environment: browser DevTools console**

## Module Goal
Students define and call functions, use parameters and return values, understand scope (local vs global), and pass by value vs reference with defensive copying.

## Pre-requisite snapshot
Unit 2 (Control Flow) complete.

## Post-requisite snapshot
Students can write a function that takes parameters, returns a value, and correctly reasons about scope and mutation.
