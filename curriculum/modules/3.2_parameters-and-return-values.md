# Module 3.2: Parameters and Return Values

## Module Goal
Students pass values into a function and hand a result back with `return`, and can say why a function that prints is not the same as a function that returns.

## Pre-requisite snapshot
Module 3.1 (Functions: Definition and Calls) complete.

## Post-requisite snapshot
Students write functions that take parameters and return values: the shape every later chapter is built from.
