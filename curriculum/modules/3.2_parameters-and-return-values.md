# Module 3.2: Parameters and Return Values

## Module Goal
Students pass values into a function and hand a result back with `return`, and can say why a function that prints is not the same as a function that returns.

## Pre-requisite snapshot
Module 3.1 (Functions: Definition and Calls) complete.

## Post-requisite snapshot
Students write functions that take parameters and return values: the shape every later chapter is built from.

roughly 1.75 contact hours per class day (`sub-module-spec-conventions.md` §1.1) is 2.85 days,

and 2.4 days before them). The old `days: 2` and the plan's "3.5 hrs" were set when the section
was sized by book line count, before the module grew to 29 lessons.

carries a weighted 20-point rubric (the two criteria it is about count 7, the rest 2, pass at
14), so a wrong call shape or a wrong order still fails the chart. `grading.formative: true`
keeps them out of the course grade: no Written category, no maxScore, never "missing".
A student still sees them as started or complete.

`week` is 7 on every 3.2 lesson (3.2.29, the unit quiz, was null until 2026-10-06).

### ⚠ Folder numbers do not match title numbers here

The Numbered Lesson List above is the slot map: its **Slot** column is the title number, its
**Slug** column is the folder (the id). **Do not rename a folder to match its title.**

These lessons keep their original folder names, because `lesson_state.lesson_id`
is the folder name and renaming one orphans student progress. Order comes from
the number in `lesson.json.title`. See `BOOK-TO-MODULE.md` §7.3.
