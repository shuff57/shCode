# Module 6.1 — Groups and Overlaps

**Quarter 2 · Week 13 · ~3.5 contact hours**
**Environment:** moSHion in-app editor.

## SLO Focus
- Reinforces **SLO 3** (design/implement/test)
- Reinforces **SLO 4** (collision detection + spawn logic are algorithms)
- Reinforces Q1 Arrays topic in a motivating new context

## Module Goal
Students level up from "one sprite" to "many sprites managed as a group." They understand collision detection as an algorithm and handle spawn/despawn logic safely.

## Pre-requisite snapshot
- Comfortable with classes and `new Sprite()` from Module 5.3.
- Remembers Q1 arrays (push, forEach, iteration).

## Post-requisite snapshot
- Can create a Group, spawn sprites into it, detect overlaps, and despawn safely.
- Has shipped the Asteroid Field challenge.
