# 1.1.3 Documentation and Coding Conventions — Teacher Slide Outline

Plain-markdown teacher outline. One `##` per session-plan row. Not wired into a slide-deck build; edit freely.

---

## Session 1

## Warm-up: "Read this code from 6 months ago"
*10 min. Show a random Week 2 student submission (anonymized) on the projector. Class reads silently for 60 seconds. Ask: "What does this program do? How long did it take you to figure that out?" Use the friction they feel as the motivation for today.*

## Worked Example 1 — Messy vs clean side-by-side
*15 min. Project both versions simultaneously. 60 seconds silent reading, then class discussion. Collect answers to: "What specifically makes the clean version easier?" Map each answer to a bullet on the style guide.*

## Distribute the Class Coding Style Guide (1-page)
*15 min. Walk through each section: indentation → semicolons → naming → comments → spacing → braces → template literals. Emphasize: "This is the grading rubric from now on."*

## Activity 1 — FCC: Understanding Code Clarity
*15 min. Individual theory reading. Students annotate any rule they already knew vs. rules that are new.*

## Activity 2 + 3 — CHS 1.8.1 Commenting video + 1.8.3 Hurdle Karel (commented)
*20 min. Video first (V1), then the example. Class discuss: where did the comments help? Where were they unnecessary?*

## Activity 4 — CHS 1.8.4 The Two Towers + Comments
*20 min. Pair work. One partner drives, one comments. Rotate halfway.*

## AP CSP Discussion — Open source and licensing
*15 min. Show the Open Source Initiative "What is open source?" page. Cover: copyright basics, MIT License, Creative Commons. Connect: q5play, JSCAD, and FCC are all open source. Ask: "What does that let you do with the code?"*

## Hand out A3.1 (Document a Messy Program)
*Due: end of Session 2. Walk through the starter file and deliverables list briefly.*

## Session 2

## Review A3.1 on screen (2–3 student examples, anonymized)
*10 min. Pick two contrasting examples — one strong, one with a pattern worth fixing. Discuss as a class.*

## Activity 5 + 6 — CHS 1.18.1 Indent video + 1.18.3 Dance and Clean Karel
*20 min. Video (V2) then example. Focus on how indentation reveals structure.*

## Worked Example 2 — JSDoc preview
*5 min. Show the `totalCost(price, taxRate)` JSDoc block. "We will write these in Week 6. For now, recognize the pattern — this is how professionals document functions." Do not require students to write one.*

## Activity 7 — CHS 1.7.1 Top Down Design and Decomposition in Karel
*10 min. Video (V3). Bridges documentation mindset to program structure.*

## Activity 8 — CHS 1.7.4 The Two Towers (decomposed)
*20 min. Pair work. Extend Activity 4 solution: add section headers as block comments, break into logical steps.*

## Worked Example 3 — README walkthrough on GitHub
*10 min. Open a real README (JSCAD repo or q5.js repo). Walk the 4 sections: title / what-it-is, install/run, usage example, link to docs. Tell students their A3.1 README follows the same pattern, just smaller.*

## Hand out A3.2 (Written — Why Documentation Matters)
*Due: end of Week 3.*

## A3.3 Quiz — Unit 1.1 closing assessment (closed-note)
*15 min. Distribute quiz. Covers all of Unit 1.1 (Weeks 1–3). Collect when done.*

## Preview Week 4 — Conditionals
*5 min. "Next week: how to make decisions in code. `if` / `else`. You've already seen the syntax in the starter file — we'll go deep."*
