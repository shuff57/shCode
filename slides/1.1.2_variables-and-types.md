# 1.1.2 Variables and Data Types — Teacher Slide Outline

Plain-markdown teacher outline. One `##` per session-plan row. Not wired into a slide-deck build; edit freely.

## Session 1

## Warm-up: "What does the computer remember?"
*5 min. Prompt: "When you close a tab, does the page remember your scroll position? Why or why not?" Use as a bridge to the idea of a variable as memory.*

## Activity 1 — CHS 3.4.1 Variables (V2)
*10 min. Play the video; pause after each new term for a quick student prediction: "What do you think `let` does?"*

## Worked Example 1 — Design-spec variables (live coding)
*10 min. Build the `width / height / depth / material / isWaterproof` program live on the projector. Discussion: `const` vs `let`, template literals, what is `false` vs `"false"`?*

## Activity 2 — Variables Deep Dive (FCC theory + CHS example)
*20 min. FCC Variables & Strings theory + CHS 3.4.3 example. Students read/work independently.*

## In-app lesson: `variables-and-types` (hands-on)
*30 min. Students complete the in-app lesson. Circulate; watch for `var`, string-value-without-quotes, and forgetting `let`/`const`.*

## Worked Example 3 — `typeof` reveals types
*5 min. Live in DevTools: age / name / enrolled / nothing / notSet. Highlight the `typeof null === "object"` quirk briefly.*

## Activity 3 — CHS 3.4.4 Apples and Oranges
*15 min. Individual exercise.*

## AP CSP Discussion — Binary number systems
*15 min. Videos V5–V7 (What is Digital Information? + Number Systems + Decimal to Binary) + Binary Game. Segue: "You just made a variable that stores 17. The computer stores that as `00010001`."*

*Due: end of Session 2.*
