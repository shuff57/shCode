---

## Teacher Worked Example 2 — SDLC with a real app *(1:40 — 1:55)*

- Draw the 5-phase cycle on the board: **Design → Development → Testing → Deployment → Maintenance**
- Walk through Instagram (or pick an app students name):
  - **Design:** "What were they trying to solve? What features did they plan?"
  - **Development:** "Engineers wrote code for the camera, filters, the feed"
  - **Testing:** "Beta users tried it before launch; bugs were found and fixed"
  - **Deployment:** "Launch day — uploaded to the App Store"
  - **Maintenance:** "Every update since: new features, bug fixes, server upkeep"
- Ask students to name another app — walk through it together
- Students take notes: they'll need all 5 phases for A1.1

## Teacher Worked Example 1 — Hello Console live demo *(0:50 — 1:00)*

- Open DevTools on the projector (`Ctrl+Shift+J` or `F12`)
- Type `console.log("hello")` — press Enter; point at output
- Change to `console.log("Mr. Smith's class")` — "the thing inside quotes is treated as text"
- Type `console.log(5 + 3)` — "no quotes means it's math"
- Ask: "What do you think happens if I type `console.log("5" + "3")`?" Run it — discuss briefly; "we'll explain this next week"
