## Task set / workflow

**Read before attempting `1.1.15 Write a Task Set`.**

What you'll learn from it:

- A task set (also called a workflow) is all the tasks required to accomplish one software engineering action.
- Each task produces a real work product, and the work product is checked before moving on.
- Task sets vary by project, and activities usually overlap rather than run independently.

**Try it:** Run the block below to see three tasks for the action "test the greeting app."

```js live plain
console.log("task 1: write test cases for the greeting");
console.log("task 2: run the tests and record the results");
console.log("task 3: fix any failures and re-run");
```

## How a task set works

What you'll learn from it:

- One action = one task set; each task in the set produces something you can check.
- The tasks are concrete steps, not restatements of the action itself.

**Try it:** Change the block to add a fourth task for the same action.

```js live plain
console.log("task 4: confirm the greeting shows correctly");
```
