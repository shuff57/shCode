## Chapter 1 Test — Part 5 of 5: Write the Steps

**Worth 20 of the 100 points on this test**, and it is the largest single item on
it. Write the **pseudocode** for the problem you charted in Part 4 -- the same
one, not a different one.

**Not JavaScript.** Plain English, arranged like code. Chapter 1 has not taught
you how to write a decision as real code, and this is not asking you to guess.

### The two rules

**One instruction per line.** If a line is doing two things, split it.

**Indent what is inside something else.** Indentation is what shows containment,
and it is doing real work — moving one line in or out describes a different
program.

Here is the shape, from 1.5.21 and 1.5.22, on a different problem:

```
get the pizza price
get the number of slices
set cost per slice to price divided by slices
if cost per slice is 2.00 or less
    report that it is a good deal
otherwise
    report that it costs too much
```

### What is being marked

- Every value the problem hands you is fetched before it is used
- The one value the problem is about is worked out, in a line that says how
- The comparison is asked as a question, and **both** answers to it are written
- The lines under each answer are indented, and nothing else is
- Plain language throughout, one instruction per line

**This is the last part.** Same rules as everywhere else on this test: one
submission, it locks, nothing comes back on screen.
