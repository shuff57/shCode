## Where prescriptive models break

**Read before attempting `1.1.21 Does It Fit?`.**

What you'll learn from it:

- Prescriptive models are rigid and inflexible.
- They are a poor fit for projects with rapidly changing requirements.
- A rigid-recipe analogy captures it: a strict recipe fails when the situation changes mid-way.

**Try it:** Run the block below to log one project type that suits a prescriptive model and one that does not.

```js live plain
console.log("fits: a well-understood project with stable requirements");
console.log("does not fit: a project where requirements change weekly");
```

## The rigid-recipe analogy

What you'll learn from it:

- A prescriptive model works when you can follow the recipe start to finish.
- It breaks when the requirements change and the model cannot bend.

**Try it:** Change the block to log your own reason a strict process is hard to follow when requirements keep changing.

```js live plain
console.log("reason: re-planning takes longer than the plan saves");
```
