## Plan before you build

A pool game is five parts: a table, a cue ball, a pointer you can pull back from, a way to
describe the shot, and a rule for when the ball stops. Answer these four questions in the box.

1. **Parts.** Name the four or five parts of the game.
2. **Remember.** What does the game have to remember between frames? (Where the ball is, its
   speed, how many shots.)
3. **First.** What will you build first, so that something runs today?
4. **Unsure.** Which part are you least sure how to build?

There is no wrong answer. A plan you can say in plain words is worth more than a clever one.
