## The four Ps

**Read before attempting `1.1.15 Same Framework, Different Weight`.**

What you'll learn from it:

- The four Ps are problem, project, people, and product.
- Every framework is elaborated differently depending on these four factors.
- Two teams can follow the same four phases and still work very differently.

**Try it:** Run the block below to log the four Ps and one sentence on what each changes.

```js live plain
console.log("problem - changes how hard the work is");
console.log("project - changes how it is managed");
console.log("people - changes who works on it");
console.log("product - changes what gets built");
```

## Why the same framework differs

What you'll learn from it:

- A big, safety-critical project is elaborated more heavily than a small internal tool.
- The four Ps are the reason the phases get more or less weight from project to project.

**Try it:** Change the block to log which P you think matters most for a banking system.

```js live plain
console.log("for a banking system, the product matters most: it must be reliable");
```
